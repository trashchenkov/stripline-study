# Автоматические проверки

Проверки не блокируют прогон. T1–T3 — код; T4–T5 — прокси-критерии и `manual_required`.

Планируемые группы:

- единицы, размеры, зазоры;
- замкнутость, самопересечения;
- потенциалы, материалы, ГВ;
- сходимость;
- пересчёт C′/W′;
- неизменность защищённых объектов;
- счётчики и сетка T5;
- сдача геометрии (`geometry_saved`) и совпадение `radius_mm` с геометрией (`radius_matches_result`);
- верхний предел с допуском на дискретизацию (`max`, `tol_rel`).

Геометрия читается из `out/geometry.json` (сданная модель), при отсутствии — из корневого `geometry.json`.
Если сдана базовая геометрия без правок, `geometry_saved` падает: отчёт без модели не принимается.

Реализация — после пилота.
