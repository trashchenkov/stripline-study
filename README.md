**Авторы статьи:** С. В. Тращенков, Н. В. Коровкин.

Материалы к статье: пять задач в FEMM 4.2, исходные условия для исполнителя, программа проверки и результаты 54 сессий. Исследовались два разных вопроса: может ли агент провести расчёт без выданной библиотеки и совпадает ли решение, принятое в диалоге, с тем, что сохранено в файлах.

**С чего начать.** Для чтения таблиц и проверки журналов не нужны FEMM, ключи API или агентские оболочки. Для сверки опубликованных таблиц выполните `python3 tools/article_tables.py --from-csv` из каталога этого README; если есть архив журналов — ту же команду без флага. Для нового расчёта поля нужен установленный FEMM; пример для купольного электрода приведён в приложении Б.

## Как устроен стенд

- [tasks/](tasks/) — задания и шаблоны рабочей папки; [schema/](schema/) — форматы сдачи. В T1 исполнитель сам строит исходную модель. Для T2–T5 сохранены два условия: с библиотекой и без неё.
- [lib/](lib/) — функции построения геометрии и вызова решателя; [tools/build_task.py](tools/build_task.py) собирает рабочую папку отдельной задачи.
- [operator/](operator/) — инструкции модели, игравшей роль инженера или студента; [runner/](runner/) — программа, которая ведёт диалог и управляет терминалом исполнителя.
- [hidden/](hidden/) и [verifier/](verifier/) — критерии и код проверки сданных файлов. Они не входят в начальную рабочую папку агента.
- [analysis/runs.json](analysis/runs.json) — список запусков статьи. В рабочем архиве `runs/<идентификатор>/` хранятся журналы, отчёты проверок и сданные файлы, если они были созданы. Весь каталог `runs/` не равен выборке статьи.

«Без библиотеки» означает, что её **не выдавали** в рабочей папке. Файловая система машины не была изолирована: в частности, в двух зачтённых запусках OpenCode нашёл готовый код за её пределами.

Полные журналы исполнителей и операторов хранятся локально: `runs/*` исключён из Git. Для чтения без архива в [галерею](docs/gallery/README.md) вынесены подлинные фрагменты реплик и экрана.

Это рабочая версия материалов, не публичный релиз архива. Собственный код — [MIT](LICENSE); FEMM устанавливается отдельно, см. [условия для сторонних компонентов](THIRD_PARTY_NOTICES.md).
